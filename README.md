# My link page

## Change a button's link

1. Click **links.js** in the file list above.
2. Click the ✏️ pencil icon (top right of the file).
3. Paste your new link between the quotes `" "`. Keep the quotes and the comma.
4. Click the green **Commit changes** button, then **Commit changes** again.
5. Wait 2–10 minutes, then refresh your site (Ctrl + F5 on PC).

## Files

- `index.html` is the page itself.
- `links.js` holds the link behind every button.
- `assets/` holds the logos, palm trees and icons.
